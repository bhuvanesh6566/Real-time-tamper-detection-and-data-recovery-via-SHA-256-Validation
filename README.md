# Real-Time Tamper Detection & Data Recovery 🔐

A security project exploring data-integrity verification with SHA-256 hashing and recovery workflows.

## Core Concepts
- SHA-256 integrity validation
- Tamper/change detection
- Data recovery workflows
- Integrity monitoring

## Getting Started
Install the dependencies used by the repository and run its main application/script.

## Security Note
SHA-256 can show that data differs from a known reference hash; it does not by itself prove who changed the data.
